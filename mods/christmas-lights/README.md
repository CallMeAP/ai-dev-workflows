# christmas-lights (Claude Code mod)

Hangs a string of Christmas lights above the prompt and counts the days to Christmas in the status line. `/christmas` turns it on or off for the session.

Install: copy this folder to `~/.claude/mods/christmas-lights`.

Not included: `.claude-plugin/types/` (the generated Claude Code type files that `tsconfig.json` extends; gitignored in the live mod). They are only needed for type checks and tests.
